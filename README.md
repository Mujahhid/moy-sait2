# bio_capybara — демо-сайт

Демо-версия сайта школы подготовки к ОГЭ и ЕГЭ по биологии [@bio_capybara](https://www.instagram.com/bio_capybara/).

Весь сайт — один файл `index.html` без сборки и без сервера: откройте его в браузере или включите GitHub Pages для ветки `main`.

## Что внутри
- Воронка: бесплатные тесты → диагностика → прогрев (цифры, преподаватели, отзывы, метод) → курсы и тарифы.
- Тесты для родителя и ученика, пробники ОГЭ и ЕГЭ (первая часть), тесты по темам.
- Тренажёры с анимациями: репликация ДНК, биосинтез белка, строение гена, транспорт через мембрану, симбиогенез, осмос, митоз и мейоз, решётка Пеннета, циклы растений и паразитов.

## Что заменить перед запуском
- Цены на курсы — условные.
- Отзывы и биография второго преподавателя — шаблоны.
- Форма записи на диагностику никуда не отправляет заявки: её нужно подключить к Telegram-боту или CRM.
- Рисунки к заданиям пробников взяты с «Решу ОГЭ/ЕГЭ» и несут их водяной знак — для публичного сайта их лучше заменить своими.

Секретов (ключей, токенов, паролей) в коде нет, переменные окружения не нужны.
