# bio_capybara — сайт

Сайт школы подготовки к ОГЭ и ЕГЭ по биологии: тесты, пробники, тренажёры и запись на диагностику с админ-панелью для заявок.

## Файлы
- `index.html` — сам сайт (одна страница).
- `admin.html` — админ-панель заявок, открывается по адресу `/admin`.
- `server.js` — сервер на Node.js без сторонних пакетов: раздаёт страницы, принимает заявки (`POST /api/leads`), отдаёт их админке.
- `package.json` — команда запуска `npm start`.

## Переменные окружения
| Переменная | Зачем |
|---|---|
| `ADMIN_PASSWORD` | Пароль от `/admin`. Пока не задан, админка закрыта. Задаётся в Railway → сервис → Variables, в коде его нет. |
| `DATA_DIR` | Необязательно. Папка для `leads.json`. На Railway берётся путь подключённого диска (`/data`). |
| `PORT` | Railway задаёт сам. |

## Локальный запуск
```
ADMIN_PASSWORD=любой-пароль node server.js
```
Сайт: http://localhost:8080, админка: http://localhost:8080/admin

## Что заменить перед запуском
- Цены на курсы — условные.
- Отзывы и биография второго преподавателя — шаблоны.
- Задания пробников составлены заново в формате первой части ОГЭ и ЕГЭ; их стоит вычитать преподавателям.
